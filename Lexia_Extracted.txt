1. Concepto Central de LexIA
LexIA no es solo un transcriptor ni solo un generador de documentos. Es un asistente de flujo de trabajo judicial completo: guía al usuario paso a paso desde el video de la audiencia hasta el documento final en Word, usando botones intuitivos para usuarios nuevos y conversación libre para usuarios expertos.
💡 La filosofía de diseño:
Usuario nuevo  →  Usa los botones guiados para no perderse
Usuario experto →  Ignora los botones y escribe directamente sus instrucciones
Ambos obtienen el mismo resultado: documentos judiciales profesionales en Word
Es como un GPS: puedes seguir la ruta sugerida o tomar tu propio camino.
1.1 El Flujo Maestro (5 pasos)
1
INGRESAR VIDEO
El usuario arrastra o selecciona el video/audio de la audiencia. Formatos: MP4, MOV, AVI, MP3, WAV. Tamaño máximo: 2GB.
2
TRANSCRIPCIÓN AUTOMÁTICA
LexIA transcribe el audio con Whisper (OpenAI). Genera un documento Word descargable con la transcripción completa. El usuario puede corregir errores antes de continuar.
3
SELECCIONAR QUÉ HACER
Aparece el panel de botones guiados. El usuario elige qué documento quiere crear o qué quiere extraer de la transcripción.
4
CONSTRUCCIÓN ASISTIDA
La IA redacta paso a paso según las instrucciones del usuario. En cada paso aparecen botones con las siguientes acciones posibles. El usuario puede usar los botones o escribir instrucciones propias.
5
EXPORTAR A WORD
Cuando el usuario indica que el documento está listo, LexIA lo exporta en Word con el formato judicial preciso indicado por el usuario.
2. Sistema de Botones Guiados — Diseño Completo
Este es el corazón de la experiencia de usuario. Cada pantalla tiene un conjunto de botones contextuales que cambian según en qué paso del flujo se encuentre el usuario. El desarrollador debe implementar estos botones exactamente como se describe.
2.1 Panel Inicial — Después de la Transcripción
Cuando la transcripción termina, aparece este panel debajo del texto transcrito:
¿Qué quieres hacer con esta transcripción?
  📋 Extraer declaraciones de testigos  
        ⚖️ Extraer alegatos de las partes
  🗂️ Resumir los puntos principales  
        📝 Iniciar Acta de Audiencia
  🏛️ Iniciar Sentencia  
        📄 Iniciar Acuerdo
  📨 Elaborar Escrito / Demanda  
        ⚡ Elaborar Demanda de Amparo
  📊 Analizar Sentencia recibida  
        ✍️ Escribir instrucción propia...
Nota para el desarrollador: El botón '✍️ Escribir instrucción propia...' abre el campo de texto libre. Los demás botones envían un prompt predefinido al motor de IA.
2.2 Flujo de Botones — SENTENCIA
Cuando el usuario elige 'Iniciar Sentencia', el sistema muestra los pasos en orden. El botón del paso actual está resaltado en dorado. Los completados muestran ✅. Los siguientes están en gris.
PASO ACTUAL EN LA SENTENCIA — Elige qué redactar ahora:
  ✅ 1. Transcripción lista  
        ▶ 2. Redactar RESULTANDO
  ○ 3. Redactar CONSIDERANDOS  
        ○ 4. Valoración de Pruebas
  ○ 5. Argumentación Jurídica  
        ○ 6. Buscar Tesis / Jurisprudencia
  ○ 7. Redactar RESOLUTIVOS  
        ○ 8. Exportar Sentencia a Word
En cada paso, adicionalmente aparecen estos botones de apoyo:
Herramientas de apoyo (disponibles en cualquier paso):
  🔍 Buscar criterio en SCJN  
        🔍 Buscar en PJENL
  🔍 Buscar en DOF  
        📚 Buscar en mis documentos
  ✏️ Mejorar redacción de este párrafo  
        ⚖️ Agregar fundamento constitucional
  🔗 Agregar tesis jurisprudencial  
        ↩️ Rehacer este paso
  💬 Dar instrucción específica...  
        ✅ Este paso está listo, continuar

4. Prompts para Antigravity — Lógica de Botones
Una vez importado el diseño de Stitch a Antigravity, estos prompts implementan la lógica funcional de cada botón guiado.
4.1 Prompt — Sistema de Botones Guiados
PROMPT ANTIGRAVITY 1 — BOTONES CON PROMPTS PREDEFINIDOS:
Implement the guided action buttons system.
Each button sends a predefined prompt to the OpenAI Assistant API.
Map each button to its prompt:
Button 'Extraer declaraciones de testigos' →
  prompt: 'Del siguiente texto de audiencia judicial, extrae y organiza
  únicamente las declaraciones de los testigos. Para cada testigo indica:
  nombre, calidad (testigo de cargo/descargo), y su declaración completa.
  Usa formato judicial mexicano. Transcripción: {transcription}'
Button 'Extraer alegatos de las partes' →
  prompt: 'Extrae y separa los alegatos de cada parte procesal de esta
  audiencia: Ministerio Público, Defensa, y víctima si aplica.',
Button 'Iniciar Sentencia - Redactar Resultando' →
  prompt: 'Redacta el RESULTANDO de una sentencia judicial con base en
  la transcripción de audiencia. Sigue el formato del Poder Judicial de
  Nuevo León. Incluye: número de expediente [usuario lo indica],
  partes procesales, antecedentes del proceso. Transcripción: {transcription}'
Button 'Buscar tesis SCJN' →
  Use web_search tool targeting scjn.gob.mx with user's current topic
Button 'Exportar a Word' →
  Compile all completed sections, apply judicial formatting,
  generate .docx file with proper headers and structure
IMPORTANT: After each button action, show the result AND then display
the next-step buttons automatically based on current document state.
4.2 Prompt — Memoria de Sesión (Contexto continuo)
PROMPT ANTIGRAVITY 2 — CONTEXTO CONTINUO ENTRE PASOS:
Implement session memory for the document building flow.
Maintain a documentState object throughout the session:
documentState = {
  transcription: string,      // original transcription
  documentType: string,       // sentencia/acta/amparo/etc
  completedSections: [],      // array of {title, content}
  currentStep: number,        // which step user is on
  userInstructions: [],       // user's custom instructions
  searchResults: [],          // saved legal search results
  formatPreferences: {}       // user's formatting choices
}
On every API call to OpenAI, include:
1. The original transcription
2. All completed sections so far
3. The user's current instruction
4. Any search results the user added
This ensures the AI always has full context and the document
is coherent from beginning to end.
5. Exportación a Word — Formato Judicial
Este es un requisito crítico. Los documentos exportados deben cumplir con el formato judicial del Poder Judicial de Nuevo León. El desarrollador debe implementar estas especificaciones:
Elemento
Especificación
Papel
Carta (Letter) 21.59 x 27.94 cm
Márgenes
Superior 3cm, Inferior 2.5cm, Izquierdo 3cm, Derecho 2.5cm
Fuente
Times New Roman 12pt para cuerpo de texto
Interlineado
1.5 o doble espacio según tipo de documento
Encabezado
Nombre del juzgado, número de expediente, tipo de documento
Pie de página
Número de página centrado
Secciones
RESULTANDO, CONSIDERANDO, RESUELVE en mayúsculas y negritas
Párrafos
Primera línea con sangría de 1.25cm
PROMPT ANTIGRAVITY 3 — EXPORTACIÓN A WORD:
Implement Word export using docx npm library.
When user clicks 'Exportar a Word', generate a .docx file with:
- Times New Roman 12pt body font
- Letter size paper with judicial margins
- Document header: [JUZGADO], Expediente: [NUM], [TIPO DE DOCUMENTO]
- Each section in caps and bold: RESULTANDO:, CONSIDERANDO:, etc.
- 1.5 line spacing
- First-line indent 1.25cm for each paragraph
- Page numbers centered at bottom
- At the end: signature spaces for judge and court secretary
File name: [TipoDocumento]_Exp[Numero]_[Fecha].docx
Trigger automatic download when generated.
6. Personalización de Botones por el Usuario
Una de las características más importantes: los botones predeterminados son un punto de partida. El usuario experto puede crear sus propios botones con instrucciones personalizadas.
6.1 Cómo Funciona
En la pantalla de elaboración, hay un botón '⚙️ Personalizar mis botones'
El usuario puede editar el texto de cualquier botón predeterminado
Puede agregar hasta 8 botones propios con nombre e instrucción personalizada
Sus botones se guardan en Firebase y aparecen cada vez que inicia sesión
Puede tener diferentes sets de botones para Sentencias, Amparos, etc.
PROMPT ANTIGRAVITY 4 — BOTONES PERSONALIZABLES:
Implement customizable quick-action buttons.
Store user's custom buttons in Firestore: users/{userId}/customButtons
Each button has: { id, label, icon, prompt, documentType, order }
Add an 'Edit buttons' mode where user can:
- Rename any default button
- Edit the prompt sent to AI when button is clicked
- Add new custom buttons (max 8 custom)
- Drag to reorder buttons
- Reset to defaults option
Show a small pencil icon on each button when in edit mode.
Save changes automatically to Firestore.

8. Nota sobre la IA — OpenAI vs Otras Opciones
El desarrollador debe saber que el motor de transcripción de audio se llama Whisper. No es una app visible para el usuario — es la tecnología que trabaja internamente cuando el usuario sube su video. Para el usuario solo existe un botón 'Subir video' y el resultado es la transcripción. Whisper fue elegido porque:
Es de los mismos creadores del GPT que Josue ya usa (OpenAI)
Es el más preciso para español mexicano con terminología legal
Se paga solo por uso — no hay mensualidad fija
Se integra directamente en la app sin redirigir al usuario a otro servicio
Para el generador de documentos, el desarrollador debe usar el Assistant ID del GPT ya creado por Josue en ChatGPT — ese 'cerebro' legal ya entrenado simplemente se conecta a la nueva app vía la API de OpenAI.
